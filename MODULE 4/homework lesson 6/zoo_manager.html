🔍 DOM Tree Information

The DOM (Document Object Model) represents the webpage as a structured tree of interconnected elements.🌳💻

  • 🌿Parent of Lion Zone: The main zoo container.
  • 🥇First child of Zoo: Lion Zone.
  • 🥈 Second child of Zoo: Elephant Zone.

🔗 Sibling Node Information

Elements positioned at the same level in the DOM are known as siblings.

➡️ Next sibling of Lion Zone: Elephant Zone.

⬅️ Previous sibling of Panda Zone: Elephant Zone.

🧩 Types of Nodes

Every element in the DOM has a specific node type.

  • 🔹Lion Zone element node type: Element Node.
  • 📝Lion Zone first child node type: Text Node.
